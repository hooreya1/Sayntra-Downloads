02

버튼을 누르기 바로 전의 짧은 소리까지 이어 받아 첫 음절 누락을 줄이도록 설계했습니다.

03

내 PC에서 텍스트로

Whisper 기반 음성 인식과 GPU 가속으로 한국어·영어 음성을 텍스트로 바꿉니다.

04

05

FAQ

확인하고
시작하세요.

현재 제공되는 것은 Windows용 베타 버전입니다. 설치와 개인정보 처리 방식에서 자주 묻는 내용을 먼저 확인해 주세요.

VERIFIED ON · 0.4.1 기준Windows 11 x64 · RTX 4070 Ti별도 PC 호환성과 장기 실사용 검증은 진행 전입니다.
인터넷 없이 사용할 수 있나요?

음성 변환 자체는 PC 안에서 수행됩니다. 다만 모델 캐시가 없다면 첫 실행 때 고정된 Whisper 모델 약 1.5 GiB를 다운로드해야 합니다. 이때는 인터넷 연결을 유지하고 트레이의 모델 상태가 준비로 바뀔 때까지 기다려 주세요. 다운로드가 중단됐다면 네트워크와 저장공간을 확인한 뒤 트레이의 다시 시도를 선택하세요.

Python이나 CUDA Toolkit을 설치해야 하나요?

아니요. 설치판에 Python과 필요한 런타임이 포함됩니다. 호환 NVIDIA GPU와 최신 NVIDIA 드라이버는 필요합니다. 최소 VRAM 기준은 아직 확정하지 않았으며, 현재 실제 검증 완료 환경은 Windows 11 x64와 RTX 4070 Ti 한 대입니다.

왜 Windows에서 경고가 나타나나요?

현재 설치 파일에 Authenticode 코드 서명이 없는 베타 버전이기 때문입니다. SmartScreen 또는 발행자 확인 경고가 나타날 수 있습니다.

어떤 언어를 지원하나요?

현재 지원 대상은 한국어와 영어입니다. 영어와 한영 혼합 발화는 추가 실사용 검증 중이며, 다른 언어의 지원 일정은 아직 정하지 않았습니다.

변환된 텍스트가 붙여넣어지지 않으면 어떻게 하나요?

녹음 뒤 포커스가 잠깐이라도 바뀌었다면 원래 창으로 돌아와도 안전을 위해 자동 입력하지 않고 결과를 클립보드에만 둡니다. 원하는 입력창에서 직접 Ctrl+V를 눌러 붙여넣으세요. 텍스트가 만들어지지 않았다면 마이크 선택과 앱 상태를 확인한 뒤 다시 시도하세요.

새 PC로 옮기면 설정도 따라오나요?

아니요. 설정은 PC별로 저장되어 자동 동기화되지 않으며, 새 PC에서는 Whisper 모델도 다시 내려받아야 합니다. 이는 저장 방식에 대한 설명이며 여러 대의 PC에서 사용할 권한을 뜻하지 않습니다. 베타 이용 조건과 버전 간 설정 이전 여부는 설치 전 릴리스 안내를 확인해 주세요.
